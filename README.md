# Small Business Automations

Small, practical Python tools for the everyday work of shops, salons and small businesses: reminders, stock, catalogs, costing, price lists, collections, quotes and sales summaries.

Each tool:

- works with the spreadsheet the business already uses (CSV exported from Excel or Google Sheets),
- runs locally, with no paid services, no accounts and no API keys,
- keeps a person in the loop: WhatsApp messages are prepared as `wa.me` links, and someone reviews and taps Send.

All data in this repository is fictional sample data.

| Tool | Problem it solves | Status |

| [stock-by-size](stock-by-size/) | Selling a size or color that is out of stock | ✅ Ready |
| [whatsapp-catalog](whatsapp-catalog/) | Sending photos and prices one by one on WhatsApp | ✅ Ready |

| price-list-updater | Updating every price by hand after a supplier increase | In progress |
